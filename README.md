# 📝 Simple To-Do List Project

## 📌 Project Description
The Simple To-Do List is a Python console application that helps users manage their daily tasks. Users can add new tasks, view all saved tasks, and exit the program. The project demonstrates the use of Python lists, loops, conditional statements, and user input.

---

## 🎯 Features
- Add new tasks
- View all saved tasks
- Display tasks with numbering
- Exit the application safely
- User-friendly menu interface

---

## 🛠 Technologies Used
- Python 3
- Visual Studio Code (VS Code)

---

```
todo_list.py
README.md
```

---

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Open the Terminal.
3. Run the following command:

```bash
python todo_list.py
```

4. Choose one of the following options:
- **1** → Add a new task
- **2** → View all tasks
- **3** → Exit the program
